# Artifacts

This repository intentionally does not track large or machine-generated artifacts needed for full DDPM training, evaluation, and checkpoint-backed inference.

The tracked result tables and figures under `counterfactual_data_build/outputs/` come from prior notebook runs. They are useful evidence of previous experiments, but they are not enough to run real backend DDPM inference.

## How To Generate Missing Artifacts

From the repository root, install dependencies and run the notebook pipeline:

```bash
pip install -r requirements.txt
python pipeline_preflight_check.py
python run_counterfactual_pipeline.py
```

For offline package/file checks:

```bash
python pipeline_preflight_check.py --skip-network
```

For RAG artifacts, start the backend and run ingestion:

```bash
uvicorn backend.main:app --reload
curl -X POST http://127.0.0.1:8000/rag/ingest \
  -H "Content-Type: application/json" \
  -d '{"force_rebuild": true}'
```

## Backend Implication

The current FastAPI backend does not require the DDPM artifacts because it uses fallback simulation. A future checkpoint-backed backend inference implementation will require at least:

- `counterfactual_data_build/outputs/tables/ddpm_upgraded_model_config.json`
- `counterfactual_data_build/processed/windows/scalers.json`
- `counterfactual_data_build/outputs/checkpoints/conditional_ddpm_upgraded_best.pt`
- enough processed or live feature data to construct a conditioning window

Until those artifacts exist and backend inference is implemented, `/simulate` remains a demo simulation endpoint.
